What is kept

Nothing. There is nowhere to keep it.

What is collected

Nothing is collected. sincefirst is a program run from a terminal by one person on their own computer. It has no server, no account, no sign-in and no analytics.

What is stored

Nothing is written to disk at all — no cache, no database, no history file. Each run asks Etsy, prints the answer, and exits. Close the terminal and there is nothing left.

Personal data

sincefirst does not use OAuth and never asks anyone to sign in to Etsy. It reads only listing data that Etsy publishes to anyone holding an API key. It does not read orders, receipts, ledgers, messages or buyer details, and no such data ever reaches it.

Etsy

Requests go to api.etsy.com carrying an API key and the search words or listing IDs being looked up, and nothing else. Etsy’s own privacy policy governs what Etsy does with those requests.
