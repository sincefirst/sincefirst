Use

sincefirst is free to use, read and modify. It is a personal project, not a service: there is no uptime to promise and nobody is on call.

Accuracy

Every figure shown is arithmetic on two numbers Etsy published: the view count and the date the item was first listed. If either is wrong or missing, the program says so rather than filling the gap. Nothing here is advice about whether to buy anything, and no listing is described as good or bad.

Rate

One search is one request. A batch of listing IDs is one request per twenty. The program only runs when the person at the keyboard runs it, so it stays far inside the limits attached to its API key.
