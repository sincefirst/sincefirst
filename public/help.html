Help

How to run it, and what the odd answers mean.

Running it

Python 3.8 or newer. No dependencies to install.

python sincefirst.py                          the demo
python sincefirst.py find "linocut print"     a search, ranked by rate
python sincefirst.py look 982854797           one or more listing IDs

Set ETSY_API_KEY to keystring:shared_secret for live data — both halves; the keystring on its own is a 403 that looks like a wrong key. With no key the program prints a fixed demo and says so at the top.

“Listed too recently for a rate to mean anything yet”

The item went up less than a fortnight ago. One view on day two is not half a view a day, it is noise. Between a fifth and a half of a search is usually this new.

“No views at all”

Etsy returned a view count of zero for something that has been listed long enough to have collected some. It is not an error and it is not a bug in the listing; about a third of every search looks like this.

“Etsy gave no view count or no first-listed date”

One of the two numbers the rate is made from was missing. Rather than substitute a guess, the listing is shown with everything that was given and no rate.

Why the bars look compressed

They are on a log scale, which is printed above them. A listing at 100 views a day does not get a bar ten times longer than one at 10 — the alternative is that everything below the busiest item in the list becomes invisible.
